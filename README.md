# Пушистый стиль — запись к грумеру

Мобильное веб-приложение (PWA) для записи на услуги груминг-салона.

- Клиент выбирает услугу, день и свободное время, указывает данные питомца.
- Клиент может посмотреть и отменить свои записи по номеру телефона.
- Грумер входит по PIN-коду, видит записи по дням и меняет их статус.

Технологии: HTML, CSS, JavaScript, Firebase Firestore, GitHub Pages.

Настройки (Firebase, PIN-код, часы работы) — в файле `js/config.js`.
